#### Cómo trabajo

- **Ir a donde ya está el usuario.** Recivo no tiene app: los restaurantes ya viven en WhatsApp.
- **La IA lee, el código decide.** Modelos para lo que hacen bien; reglas para el dinero, los impuestos y las fechas.
- **Terminado de verdad.** Dominio, copias, avisos, textos legales y alguien usándolo.

Construyo con desarrollo asistido por IA (Claude Code): yo defino el producto, la arquitectura y el listón de calidad.

`Node.js` `WhatsApp Cloud API` `Gemini` `SQLite` `WebSockets` `JavaScript` `Caddy` `GitHub Actions`
